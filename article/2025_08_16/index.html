テーブルを縦持ちから横持ちに変更する

Chokoco

8月 16, 2025

QuickSightでテーブルを縦持ちから横持ちに変更した

※2023年ごろに書いていたメモを記載しています。

以下のようなデータが入ったテーブルがあったとする

  • Table Name: survey
uidquestionanswersentence
10‘0001’X何で知りましたか
2‘0002’car何できましたか
21‘0001’instagram何で知りましたか
6‘0001’facebook何で知りましたか
11‘0002’bus何できましたか

このようなテーブルをid,Question, Answerのような並びにしたい。

その時に使用するのがmax関数を使用することで縦持ちのテーブルを横持ちに変更することができる。

SELECT 
uid,
max(case when question='0001' then senstence else null end) as Question1,
max(case when question='0001' then answer else null end) as Answer1,
max(case when question='0002' then senstence else null end) as Question2,
max(case when question='0002' then answer else null end) as Answer2
FROM "survey"
GROUP BY uid
ORDER BY uid ASC

このようなSQLを書くことで横並びのテーブルに変更できる。

idQuestion1Answer1Question2Answer2
2何で知りましたかnull何できましたかcar
6何で知りましたかfacebook何できましたかnull
10何で知りましたかX何できましたかnull
11何で知りましたかnull何できましたかbus
21何で知りましたかinstagram何できましたかnull

Excel（or スプレッドシート）のFilter機能を使うことで特定のユーザーや特定の回答に絞ることでよりデータが分析しやすくなる。
