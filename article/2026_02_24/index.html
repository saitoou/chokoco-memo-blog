sync.Onceと環境変数の読み込みについて

アプリを立ち上げた際に一度だけ実行したい処理などがあると思います。 それらの要望を叶えるのが、golangのsync.Onceです。

sync.Onceについて

syncパッケージには処理を一回のみの実行を担保するOnce型が提供されている。これを用い、Doメソッドで呼ぶことで複数回呼び出されても一回のみしか実行しないようにできます。

以下に例を示します。goの公式ドキュメントにあるコードです。 こちらを実行すると、for文の中で10回繰り返しDo()を読んでも最初の一回のみしか実行されません。

package main

import (
	"fmt"
	"sync"
)

func main() {
	var once sync.Once
	onceBody := func() {
		fmt.Println("Only once")
	}
	done := make(chan bool)
	for i := 0; i < 10; i++ {
		go func() {
			once.Do(onceBody)
			done <- true
		}()
	}
	for i := 0; i < 10; i++ {
		<-done
	}
}


>>> go run main.go               
Only Once

環境変数の読み込みライブラリとの併用

これだけでも十分なのですが、golangには環境変数を読み込むライブラリ、Viperという便利なものがあります。 この環境変数を読み込むのは基本的にアプリの実行時のみだと思いますので最初の一回のみで完結させたいです。

何回も読み込みが実行されるのも無駄なので、sync.Onceを使って実行時の一回のみ読み込ませるようにすると以下のように書けます。 こちらはconfig.yamlに環境変数があらかじめ書いてあり、それを実行時1回のみ読み込んでいるのを確認しているコードです。

package main

import (
	"fmt"
	"strings"
	"sync"

	"github.com/spf13/viper"
)

type Config struct {
	Db DBConfig `json:"db" yaml:"db"`
}

type DBConfig struct {
	UserName string `json:"username" yaml:"username"`
	Password string `json:"password" yaml:"password"`
}

func Load() (*Config, error) {

	viper.SetConfigName("config")
	viper.SetConfigType("yaml")
	viper.AddConfigPath(".")

	viper.SetDefault("db.username", "default_user")
	viper.SetDefault("db.password", "default_pass")

	viper.SetEnvKeyReplacer(strings.NewReplacer(".", "_"))
	viper.AutomaticEnv()

	if err := viper.ReadInConfig(); err != nil {
		return nil, fmt.Errorf("No config file found")
	}

	var cfg Config
	if err := viper.Unmarshal(&cfg); err != nil {
		return nil, fmt.Errorf("unmarshal error: %s", err)
	}

	return &cfg, nil
}

// 環境変数をViperを使って読み込む。
// SyncOnceを使うことで何回も読み込む必要がなくなる。

func main() {
	var once sync.Once
	onceBody := func() {
		onceCfg, _ := Load()
		fmt.Printf("cfg=%+v \n", onceCfg)
	}

	done := make(chan bool)
	for i := 0; i < 10; i++ {
		go func() {
			once.Do(onceBody)
			done <- true
		}()
	}
	for i := 0; i < 10; i++ {
		<-done
	}
}

>>> go run main.go
cfg=&{Db:{UserName:yaml_test Password:yaml_test}}

このように一回のみ読み込むことが確認できました。

自身もgolangのアプリを開発した際に、実際にsync.Onceを使用して環境変数をアプリ実行時のみにすることで無駄に何回も読み込むことがないように対応しました。
