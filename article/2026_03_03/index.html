golangのembedding

embeddingを使用することで、差し替えが簡単になったり元のコードを変更せずに機能追加できる。 以下のコードでembeddingについて示す。

package main

import (
	"errors"
	"fmt"
	"io"
	"strings"
)

type LoggingReader struct {
	io.Reader
}

func (lr *LoggingReader) LoggingReader(p []byte) (int, error) {

	if lr.Reader == nil {
		return 0, errors.New("Error: reader is nil")
	}
	n, err := lr.Reader.Read(p)

	if err != nil {
		if err == io.EOF {
			fmt.Printf("[INFO] EOF n=%d\n", n)
		}
		fmt.Printf("[ERROR] read failed: %v\n", err)
		return n, fmt.Errorf("loggingReader read error: %w", err)
	}

	fmt.Printf("[INFO] read success n=%d\n", n)
	return n, nil

}

func main() {
	r := &LoggingReader{Reader: strings.NewReader("test")}
	buf := make([]byte, 4)
	_, _ = r.Read(buf)
	fmt.Println(string(buf))
}

これはio.Readerを埋め込み、Readを再作成しLoggingReaderのレシーバーとして使えるようにしています。 こうすることで以下のようなコードがあった場合に差し替えが楽になります。

func Process(r io.Reader) {
    buf := make([]byte, 4)
    r.Read(buf)
}

Process(strings.NewReader("test"))

Process(&LoggingReader{Reader: strings.NewReader("test")})

両方の渡し方ができます。 これを考えると差し替えることが容易にできることがわかるかと思います。 また、もともとあったstrings.NewReaderのコードは一切変更せずにProcessの追加ができました。

またHTTPボディをログ付きにしたい時、


resp, _ := http.Get("https://example.com")

body := &LoggingReader{Reader: resp.Body}

io.Copy(os.Stdout, body)

とすることで簡単にログ機能の追加ができます。 このようにして埋め込み機能を使うことでより拡張性に優れ、修正には閉じているようなコードの実現ができます。
